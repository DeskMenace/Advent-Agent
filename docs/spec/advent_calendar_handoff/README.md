# AI Advent Calendar — coding-agent handoff

Start with **[DESIGN_SPEC.md](DESIGN_SPEC.md)**. It specifies screens, visual tokens, 24-envelope behavior, date locks, animation sequences, gift viewers, the local AI-agent integration, scheduling, purchase permissions and acceptance tests.

- **`advent_calendar_mockup.html`**: open this browser file to experience the existing prototype. Use *Try the demo* and select December 8; door 9 should remain locked. Open door 6 to inspect a downloadable card; door 3 demonstrates an inline video.
- **`reference/physical-envelope-calendar.jpg`**: the original photographed Advent calendar that inspired the design.
- **`previews/calendar-desktop.png`** and **`previews/calendar-mobile.png`**: calendar layout references.
- **`previews/gift-card-desktop.png`** and **`previews/gift-video-desktop.png`**: two gift presentation examples.

The HTML is a self-contained **visual prototype**, not a production implementation. Its media and gifts are illustrative samples. Do not treat the hardcoded 24 gift entries as a rigid gift-generation plan. The specification describes the complete intended product, not a phase-one subset.
