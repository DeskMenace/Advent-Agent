The invaders are the punchline: each wave should make the recipient groan with recognition.
Great: invaders labelled with real error codes, a boss called "Works On My Machine", and a victory screen listing "bugs fixed this year: all of them (eventually)".
Lazy: a stock invaders clone with the word "bug" in the title.
Pitfall: pasting real stack traces or file paths that reveal private code.
