Scope ruthlessly: one mechanic done well, a difficulty curve, a satisfying end screen.
Great: a 60-second snowflake catcher with juicy particles, a combo meter, a personal high-score message and a pause button that actually pauses.
Lazy: a canvas that draws a square and calls it a game, or a game that only works with a keyboard.
Pitfall: shipping untested; play it to the end at least twice, on a narrow viewport too.
