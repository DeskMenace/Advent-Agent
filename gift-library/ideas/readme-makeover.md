Clarity first, charm second: a README is for the next person.
Great: a rendered preview with a hand-drawn banner, a two-line pitch, a copy-paste quick start that actually works and badges only if they are true.
Lazy: adding emoji to every heading.
Pitfall: claiming features or compatibility the project does not have.
